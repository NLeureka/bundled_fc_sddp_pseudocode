# bundled_fc_sddp_pseudocode
Code for Unlocking long-term flexibility of cascade hydropower for wind and solar integration through bundled flood-control storage allocation

## Code availability statement


This repository provides the pseudocode of the SDDP model formulation (`pseudocode/`), which outlines the structure of the policy graph, the state variables, the stagewise uncertainty, the constraints, and the objective described in Sections 2 and 3 of the paper. Users who wish to apply the framework to their own systems need to supply their own data, including inflow series, VRE capacity factors, reservoir characteristics, flood-control requirements, and the planned output, and implement the formulation following the paper and the pseudocode.
